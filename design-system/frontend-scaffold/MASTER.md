# Frontend Scaffold 设计基线

本文件记录组件实现前的视觉与交互约定。它是中性的工程基线，不定义具体产品的品牌风格。实际代码中的变量以 `src/shared/styles/index.css` 为准。

## 设计变量

| 用途     | 浅色      | 深色      | CSS 变量             |
| -------- | --------- | --------- | -------------------- |
| 页面背景 | `#f8fafc` | `#0f172a` | `--background`       |
| 主要文字 | `#0f172a` | `#f8fafc` | `--foreground`       |
| 表面     | `#ffffff` | `#1e293b` | `--card`             |
| 主操作   | `#4338ca` | `#a5b4fc` | `--primary`          |
| 次要文字 | `#475569` | `#cbd5e1` | `--muted-foreground` |
| 边框     | `#cbd5e1` | `#475569` | `--border`           |
| 危险状态 | `#b91c1c` | `#fca5a5` | `--destructive`      |

字号以浏览器默认的 16px 为基础。正文行高建议至少 1.5；输入框字号不低于 16px。优先使用系统字体，组件不依赖远程字体资源。间距从 4、8、16、24、32px 扩展，圆角基准为 12px。

## 响应式与交互

- 移动端优先，从 360px 开始设计；检查 390px、768px、1280px。
- 容器使用流式宽度与最大宽度，避免按单一设计稿比例缩放。
- 触控目标至少 44 × 44px；键盘焦点必须可见。
- 必要信息不得只在悬停时出现；错误信息应靠近对应输入。
- 尊重系统的减少动态效果设置；用加载状态反馈等待中的操作。
- 使用 `viewport-fit=cover` 与安全区域变量处理手机底部和侧边留白。
- 正文对比度目标为 WCAG AA 4.5:1。颜色不作为状态的唯一表达方式。

## 后续组件的检查顺序

1. 语义化结构、键盘操作与标签。
2. 触控尺寸、按下反馈和移动端弹层行为。
3. 加载、空、错误、禁用状态。
4. PC/H5 排版、系统深浅色与减少动态效果。
5. 资源大小和按需加载。

本基线参考 `ui-ux-pro-max` 的可访问性、触控与响应式检查项；具体产品视觉风格应在设计要求明确后单独确定。
